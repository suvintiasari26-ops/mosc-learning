# Folder gambar materi 1.2

Gunakan file gambar berikut untuk menempatkan ilustrasi sebelum dan sesudah kalimat “Contoh sederhana pada perusahaan makanan”:

- `1.2-before.svg`
- `1.2-after.svg`

Anda bisa mengganti file SVG tersebut dengan gambar PNG/JPG sesuai kebutuhan.
Nama file yang dipakai di konten adalah:

- `assets/materi/1.2/1.2-before.svg`
- `assets/materi/1.2/1.2-after.svg`

Jika ingin mengganti format file, pastikan path tetap sama dan nama file tetap sesuai pattern.
